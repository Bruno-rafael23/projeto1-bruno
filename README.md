# Projeto 1 Bruno

## Visão geral

Este projeto tem como objetivo desenvolver um aplicativo de recomendação gastronômica que ajuda as pessoas a encontrar restaurantes, lanchonetes e pontos de interesse culinários mais adequados ao seu perfil.

A solução considera:
- gostos pessoais do usuário;
- comidas típicas da região;
- avaliações online;
- localização e contexto do momento.

Em vez de o usuário pesquisar restaurante por restaurante, o sistema entrega as principais opções relevantes de forma rápida, prática e personalizada.

## Problema resolvido

Muitas pessoas perdem tempo escolhendo onde comer porque precisam comparar diversas opções manualmente. Isso gera frustração, indecisão e dificuldade para encontrar locais que realmente correspondam ao seu gosto.

## Proposta de valor

O aplicativo busca:
- reduzir o tempo de pesquisa;
- indicar opções com maior alinhamento ao perfil do usuário;
- destacar comidas típicas da região;
- considerar avaliações e reputação;
- facilitar a descoberta de bons pontos gastronômicos.

## Público-alvo

- pessoas que querem comer bem sem perder tempo;
- viajantes em busca de comida típica da região;
- usuários com preferências específicas de culinária;
- pessoas que valorizam avaliações e recomendações práticas.

## Objetivo do MVP

O MVP tem como foco validar a ideia central do produto com um conjunto mínimo de funcionalidades, incluindo:
- cadastro/login simples;
- preferências gastronômicas do usuário;
- filtro por região e tipo de comida;
- ranking de opções com base em avaliação e relevância;
- apresentação dos principais pontos de interesse.

## Funcionalidades principais

1. Cadastro e autenticação do usuário
2. Definição de preferências culinárias
3. Busca por região/localização
4. Filtro por tipo de comida e culinária local
5. Listagem dos principais pontos de interesse recomendados
6. Exibição de avaliações e informações essenciais do local
7. Sugestão de opções mais adequadas ao perfil do usuário

## Arquitetura proposta

### Frontend
- interface web ou mobile para interação com o usuário
- telas para login, busca, filtro e resultados

### Backend
- autenticação
- lógica de filtros e recomendação
- consulta de dados de restaurantes e avaliações

### Banco de dados
- usuários
- restaurantes/pontos gastronômicos
- preferências do usuário
- avaliações e classificações

## Tecnologias sugeridas

O projeto pode ser implementado com tecnologias modernas como:
- HTML, CSS e JavaScript
- Python com Flask ou FastAPI
- SQLite ou PostgreSQL
- API REST para integração entre frontend e backend

## Fluxo do usuário

1. O usuário entra no aplicativo.
2. Define suas preferências culinárias.
3. Indica a região ou localização atual.
4. O sistema filtra as opções mais relevantes.
5. O aplicativo apresenta os principais pontos de interesse.
6. O usuário escolhe a melhor opção com mais facilidade.
